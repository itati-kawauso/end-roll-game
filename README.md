# THE END ROLLER - エンドロール・プレイグラウンド

映画の黒背景と白文字で流れるエンドロール上で遊べるシネマアクション＆ミニゲーム集です。

---

## 🎮 収録ゲームモード

1. **クレジット・サバイバー (Credit Climber / Survivor)**
   - 上昇し続けるスタッフロールの行を足場にして上端の圧殺ラインと下端の落下ラインを回避しながら生存を目指すアクションゲーム。
   - 💥トラップ、❤️ケータリング回復、⚡超高速暴走レール、▲ワイヤー大ジャンプ、👻崩落カットなど多彩なギミックを搭載。

2. **エンドロール・インベーダー (Credits Invader)**
   - 画面上部から降下してくるスタッフロールを1文字ずつ撃ち抜くシューティングゲーム。
   - 各文字単位の「歯抜け」破壊、怨念誘導弾（リベンジ弾）、配給会社風メガボス、ボス限定ドロップのサテライト子機、最大Lv.10+の弾幕強化を搭載。

3. **違和感エンドロール捜査官 (Glitch Inspector)**
   - エンドロール内に紛れ込んだ文字化け、極長ネーム、不穏な役職（「真の黒幕」「架空のスタッフ」）、上下反転、鏡面、激震テキストなどの違和感を画面上端に到達する前に指摘する検知ゲーム。

## 🚀 GitHub Pages への公開手順

本プロジェクトは **GitHub Pages に完全対応** するよう最適化されています（アセット相対パス `base: './'`、SVG Favicon、404リダイレクト、Jekyll無効化 `.nojekyll` 設定済み）。

### 方法1: GitHub Actions による自動公開（推奨・最も簡単）

1. このリポジトリを GitHub にプッシュします。
2. GitHub のリポジトリ画面で **「Settings」タブ** を開きます。
3. 左メニューの **「Pages」** を選択します。
4. **「Build and deployment」 > 「Source」** のプルダウンを **`GitHub Actions`** に変更します。
5. リポジトリ内の `.github/workflows/deploy.yml` が自動認識され、プッシュするたびに自動でビルド＆公開されます。
6. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でゲームが公開されます！

### 方法2: 手動ビルドによる公開

```bash
# 依存関係のインストール
npm install

# 本番用ビルド（dist/ ディレクトリに静的HTML/CSS/JSが出力されます）
npm run build
```

生成された `dist/` フォルダの中身を、GitHub リポジトリの `gh-pages` ブランチやルート、またはお好みの静的ホスティング（Cloudflare Pages, Vercel, Netlify など）にデプロイするだけでそのまま動作します。
